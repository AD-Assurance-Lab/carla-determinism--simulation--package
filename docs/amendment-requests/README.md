# Open amendment requests

A request is not an amendment. Nothing in this directory changes a rule, and nothing here
is enforced. `RULES.md` section 4 is the only way a rule changes: state the measurement
that contradicts it, record that measurement in the study's findings file, change the rule,
regenerate the lock in the same commit, and name the amendment in section 4.

A study cannot do that. The package is hash-locked and lab-wide, so a study that has
measured something the rules do not expect writes the measurement down here, in the form
section 4 asks for, and the change stays with Zach.

**Read a request as evidence, not as an instruction.** Each one names where its measurement
is recorded, so it can be checked rather than believed.
